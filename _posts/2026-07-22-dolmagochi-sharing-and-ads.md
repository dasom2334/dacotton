## 나눠 주는 김에 광고도 붙여 보고 싶었다

돌마고치는 집중 타이머가 돌아가는 동안 돌을 키우는 웹 게임이다. 혼자 쓰려고 만든 이 게임을 친구들에게 나눠 주고 싶어졌고, 7월 22일 저녁 Claude Code에 광고도 한번 붙여 보고 싶다고 물었다. 이날은 코드를 거의 바꾸지 않고, 광고가 이 게임에서 어떻게 작동하는지 묻고 확인하는 데 시간을 썼다.

## 보이지 않는 광고는 돈이 되지 않는다

처음 확인한 것은 수익 구조였다. 광고비는 대부분 실제로 화면에 보인 노출(viewable impression)과 클릭에 붙는다. 돌마고치는 타이머를 켜 두고 화면을 보지 않는 시간이 길다. 그래서 집중 화면의 광고는 거슬리지 않는 대신 거의 보이지도 않는다. 디스플레이 광고를 누르는 비율은 보통 노출 100번에 0.1~1번이고, 친구 규모 방문으로는 수익이 사실상 0원이라는 계산이 나왔다.

이 계산을 보고 나는 광고의 목적을 수익이 아니라 광고를 직접 붙여 보는 경험으로 정리했다. 그 다음에는 집중을 끊지 않는 형태를 정했다.

| 정한 것 | 누가, 왜 |
| --- | --- |
| 광고는 기본 꺼짐, 설정에서 켠 사람에게만 보임 | 내가 광고 켜기·끄기와 '개발자에게 커피 한 잔' 링크를 묶은 후원 메뉴를 제안했다. 켜는 행동이 곧 동의라 강요가 없다 |
| 팝업 없이 화면 안의 고정 자리만(넓은 화면은 양옆, 좁은 화면은 맨 아래) | 내가 정했다. 집중을 끊지 않는다 |
| 광고를 보거나 눌러도 게임 보상은 없음 | 집중한 시간이 돌을 키우는 게임의 기본 규칙을 지키고, 클릭에 보상을 거는 것은 애드센스 정책 위반이다 |
| 후원 메뉴는 기존 설정 창 안에 | Claude Code가 코드를 살펴보니 설정 창에 하위 화면을 붙일 자리가 이미 있었다 |

## 심사 기준을 웹에서 다시 확인했다

나는 직접 만든 연습용 광고로 끝내지 말고 실제 애드센스 승인을 받아 보자고 정했다. Claude Code는 '콘텐츠 부족'으로 거절될 위험이 가장 크다고 했다. 나는 이 게임이 콘텐츠가 부족하다는 판정이 납득되지 않아 기준이 정말 그런지 물었다. Claude Code는 그때까지의 설명이 웹 확인 없이 한 추정이었다고 인정하고 검색으로 다시 확인했다.

| 확인한 것 | 내용 |
| --- | --- |
| 화면을 자바스크립트로 그리는 방식(CSR) | 구글 크롤러는 자바스크립트를 실행해서 보므로 이것만으로 거절되지는 않는다. 서버에서 그리도록 바꿔도 읽을 글이 늘지 않아 해결책이 아니다 |
| 캔버스 그림뿐인 화면 | 그려진 페이지에 읽을 글이 거의 없는 게임 화면이 거절된 사례가 실제로 있었다("empty canvas problem") |
| 글을 숨겨 넣기 | 화면에 안 보이게 글을 채우면 정책 위반(cloaking)이다 |
| 통과 방법 | 게임 옆에 소개·플레이 방법·개발 노트·개인정보 처리방침 같은 실제 글 페이지를 붙이면 브라우저 게임 사이트도 승인될 수 있다 |
| 게임 전용 광고 제품(H5 Games Ads) | 있지만 애드센스 승인이 먼저 필요하고, 형식이 전면 광고·보상형이라 팝업 없음 결정과 맞지 않는다 |
| 다른 광고망 | 모바일 앱 전용이거나, 전면 광고나 다른 페이지로 넘기는 광고를 팔아서 이 게임에는 맞지 않았다 |

Claude Code는 게임 맨 아래에 작은 링크(소개·만든 이야기·개인정보)를 두고, 게임과 같은 색과 글꼴로 꾸민 별도 글 페이지를 만드는 구조를 제안했다.

## 결과

광고를 붙이려면 광고 코드보다 게임 밖의 글 페이지를 먼저 쓰고 계속 관리해야 한다는 것을 알게 됐다. 광고 형태와 원칙은 정해 두었지만, 광고·후원 메뉴·글 페이지는 아직 게임에 들어가 있지 않다. 작업 노트에는 애드센스를 신청할 때 다시 꺼낼 일로 남겨 두었다. 같은 조사에서 나온 저장 문제, 곧 주소를 옮기면 기기에 저장된 세이브가 사라지는 문제는 [그날 밤 이어진 서브도메인 이전](/log/2026/07/23/dolmagochi-own-address/)에서 다뤘다.

## 검증 범위

애드센스 심사를 실제로 신청하거나 광고를 붙여 본 적은 없다. 수익이 거의 0원이라는 판단은 노출 구조와 일반적인 클릭 비율로 한 계산이고 실측이 아니다. 거절 사례와 통과 방법은 7월 22일 웹 검색으로 확인한 내용이며, 구글 고객센터 게시글 일부는 본문을 읽지 못했다. 광고를 붙이지 않은 이유는 9월 18일 내가 직접 설명한 내용과 작업 노트를 따랐다.
