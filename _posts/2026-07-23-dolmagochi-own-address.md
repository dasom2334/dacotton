## 주소가 달라지면 저장소도 달랐다

돌마고치는 돌의 상태와 기록을 서버가 아니라 브라우저의 IndexedDB에 저장한다. 같은 게임을 다른 사이트 주소로 열면 이전 주소의 저장소를 그대로 읽지 못한다. 당시 GitHub Pages 주소에서 다른 호스팅 주소로 옮기면 기존 세이브도 직접 옮겨야 했다.

친구들에게 나눠 준 뒤에도 오래 유지할 수 있도록 개인 도메인 아래 게임 전용 서브도메인을 붙였다. 여러 게임을 같은 도메인의 하위 경로에 넣는 대신 저장 공간도 게임별로 나누는 선택이었다.

## 주소는 유지하고 호스팅을 바꾸도록

GitHub Pages에서 Vercel로 옮기면서 빌드의 기본 경로를 `/dolmagochi/`에서 `/`로 바꿨다. 첫 배포가 흰 화면이었던 것은 새 경로 설정이 아직 main에 없어서였다. 수정한 PR #43을 병합한 뒤 새 주소에서 게임과 방 그림, 분위기 바가 나타나는 것을 확인했다.

GitHub Pages 배포 작업을 지울 때는 그 안에서 함께 돌던 테스트·데이터 검사를 별도 CI로 남겼다. 호스팅을 바꾸는 일이 검사까지 없애는 변경이 되어서는 안 됐다.

앞으로 같은 주소를 유지하면 호스팅 업체가 바뀌어도 브라우저가 보는 저장 위치는 유지된다. 다만 이전 Pages 주소에서 쌓은 세이브는 자동으로 따라오지 않는다. 그 데이터는 기존의 내보내기·불러오기 기능으로 옮겨야 했다.
